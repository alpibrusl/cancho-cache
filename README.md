# lexsys-cache

A Redis-compatible cache written in [lex-sys](https://github.com/alpibrusl/lex-sys): no `Ffi`, no `unsafe`, and a
checkable authority report. **Design stage: nothing is built.** `docs/design.md` has the plan, the pre-registered performance
gate, and the measured Redis baseline it is held to.
